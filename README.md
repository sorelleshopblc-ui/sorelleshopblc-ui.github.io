# Sorellé Shop

Phase 2 foundation for a GitHub Pages storefront selling elegant bags, dresses, wallets, and accessories, with a separate coquette dress rental catalog.

## Project structure

- `index.html` — GitHub Pages entry file
- `assets/css/styles.css` — global theme and responsive layout
- `assets/js/main.js` — mobile navigation behavior
- `assets/images/` — product and brand images
- `pages/` — future category, product, rental, and policy pages
- `.nojekyll` — serve the project as a plain static website

## Planned next phase

Phase 3 will build the complete homepage, including the final hero, collection previews, featured products, rental promotion, reviews, and footer.

## GitHub Pages publishing

Use the `main` branch and publish from the repository root.
